# Data Science Portfolio

A collection of data science projects focused on **data analysis, data cleaning, visualization, and machine learning** using Python and its data science ecosystem.

The projects in this repository are built to strengthen practical skills through the full data science workflow — from exploring and preparing data to developing, evaluating, and improving machine learning models.

## What You'll Find

* Data exploration and analysis
* Data cleaning and preprocessing
* Data visualization
* Feature engineering
* Machine learning models
* Model evaluation and experimentation
* Reusable Python code

## Tools & Technologies

* Python
* pandas
* NumPy
* scikit-learn
* Matplotlib
* Seaborn
* JupyterLab

## Projects

This repository contains multiple data science projects, each focused on a different dataset, problem, or technique.

* [Notebooks](../notebooks) — Exploratory analysis, experiments, and documented workflows
* [Source Code](../src) — Reusable Python code and project utilities
* [Models](../models) — Saved machine learning models and related artifacts

## Goal

The goal of this repository is to continuously build practical data science skills while developing projects that demonstrate clear analysis, sound machine learning practices, and reproducible workflows.
